# Ateliê Vidrado | Loja online (projeto de demonstração)

Loja online fictícia de cerâmica feita à mão, criada para demonstrar como funciona um e-commerce completo para pequenos negócios. Não é uma loja real e nenhum pedido é processado.

## O que a loja faz

- Catálogo com 8 peças e filtro por categoria (canecas, tigelas, vasos e pratos)
- Sacola de compras com ajuste de quantidades
- Cálculo de frete por CEP (simulado), com frete grátis acima de R$ 250
- Desconto de 5% para pagamento no Pix
- Tela de confirmação do pedido
- Layout adaptado ao celular e ao tema claro ou escuro do aparelho

## Como abrir

1. Baixe ou clone esta pasta.
2. Abra o arquivo `index.html` no navegador.

Não precisa instalar nada.

## Tecnologias

HTML, CSS e JavaScript puros, sem bibliotecas. As ilustrações das peças são desenhadas em SVG, então não há imagens externas.

## Como seria em um projeto real

Nesta versão os dados e o frete são simulados. Em uma loja de verdade, o catálogo viria de um painel de cadastro, o frete de uma API dos Correios ou transportadora, e o pagamento de um serviço como Mercado Pago ou Pix por gateway.
